Four views of the RAIS publications recorded in ERef, the University of Bayreuth repository. Each page can be embedded in another website as an iframe, with its own controls and filters.

Semantic map

Publications placed by what their title, keywords and abstract say, grouped into topics.

Keyword network

Author keywords linked when they appear on the same publication.

Co-author network

Authors linked by their joint publications.

Dashboard

Publications by year, type, topic, keyword and author, with the full list.

Embed a visualisation

Paste the snippet into any HTML page. The script after the iframe resizes it to its content; paste it once per page even with several iframes. Any filter can be preset in the URL: year=2023-2025, type=article,preprint, keyword=Explainable AI (XAI), author=Kühl, Niklas, cluster=3. Every page also has a Copy embed code button that captures its current filters.
